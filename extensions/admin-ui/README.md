# extensions/admin-ui

Optional **Admin UI extensions** (admin blocks / actions) that surface GST Engine data on
native Shopify admin order and customer pages — e.g. an "Invoice" block on the order page
showing invoice number/status with download and resend actions.

Generated as needed (M9). The primary admin experience is the embedded Polaris app in
`apps/shopify`; these extensions are convenience surfaces inside Shopify's own admin pages.
